# Manuscript result provenance — Multimedia Systems submission version

This map corresponds to the clean *Multimedia Systems* manuscript and Online Resource 1 supplied with the submission package. Online Resource 1 uses Tables S1–S16; the mapping below follows those table numbers and the section references in the manuscript.

| Manuscript item | Repository evidence and implementation |
|---|---|
| Main manuscript Table 1 (equal-weight mean across Erase40, Randomcrop50, Cornercrop50 and Retain20 for the six localized allocations) | Per-attack descriptive results: `results_summaries/final_descriptive_by_attack.csv`; per-image records: `results_raw/main_COCO500_results.csv` and `results_raw/main_DIV2K100_results.csv`; evaluation runner: `scripts/run_fixed_budget_exp.py`; summary/statistical analysis: `scripts/analyze_final_stats.py`. The four-edit means in Table 1 are the unweighted means of the four corresponding attack-level scores. |
| Online Resource 1, Table S1 (allocation strategies and placement rules; Section S2) | Configuration: `configs/experiment_config.yaml`; allocation, placement and regional-readout implementation: `watermark_anything/redundant_region.py`; evaluation runner: `scripts/run_fixed_budget_exp.py`; realized-area and per-attack results: `results_summaries/final_descriptive_by_attack.csv`. The policy definitions themselves are stated in Online Resource 1. |
| Online Resource 1, Table S2 (regional readout variants; Section S3) | Readout implementation: `watermark_anything/redundant_region.py`; ablation analysis: `scripts/analyze_ablation_clean500.py`; descriptive results: `results_summaries/vote_descriptive.csv`; paired tests: `results_summaries/vote_paired_tests_holm.csv`; underlying ablation records: `results_raw/rho_vote_ablation.csv`. |
| Online Resource 1, Table S3 (four controlled local-edit protocol definitions; Section S4) | Attack operations are implemented in `scripts/run_fixed_budget_exp.py` and configured in `configs/experiment_config.yaml`; per-image outputs are recorded in `results_raw/main_COCO500_results.csv` and `results_raw/main_DIV2K100_results.csv`. `Retain20` is the manuscript name for implementation label `splicing20`; it restores pixels from the same unwatermarked source image and is not cross-image semantic splicing. |

The repository contains the authors' regional-allocation/readout add-on, evaluation and analysis scripts, configurations, and selected experiment records. It does not redistribute the upstream WAM source repository or checkpoint, LaMa weights, COCO/DIV2K image files, or the full COCO annotation archive. Obtain those materials separately from their respective sources and under their applicable terms. The LaMa inpainting experiment is a separate object-level stress test; it does not replace the four controlled local-edit protocols used for the main comparison.
